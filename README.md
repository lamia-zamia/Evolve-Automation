# Evolve Automation

Evolve Automation is a userscript for Evolve Incremental. It automates recurring game decisions and adds optional
controls, planning information, diagnostics, and settings for players who want more control over a run.

## Differences from the original script

Compared with Vollch's original script, this version includes:

- Morale-aware tax handling, Hell garrison stationing, and Authority-focused building weighting.
- More stable power and storage automation with less bouncing between competing actions.
- Optional achievement guards for Pacifist, Dreaded, Cult of Personality, Anarchist, Energetic, Red Dead, Second
  Evolution, World Domination, Syndicate, Trade Federation, and Banana Republic goals.
- A Script Planner panel, active-target details, state logging, and state-log export.
- Challenge and scenario helpers for Inflation Wheelbarrow, Banana Republic, and Magic Fullmetal objectives.
- Expanded weighting rules for Authority, Banana Republic objectives, and Inflation money goals.
- Focused settings sections for interface options, state logging, achievement guards, and challenge helpers.
- Automation coverage across combat, government, economy, production, resources, progression, research, evolution,
  prestige, fleets, mechs, traits, and related game systems.
